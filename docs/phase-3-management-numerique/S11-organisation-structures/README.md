> [!NOTE]
> **Question qui guide la séance :** *« Comment répartir les tâches, le pouvoir et la coordination ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Comparer les structures **fonctionnelle, divisionnelle, matricielle, par projet**
2. Distinguer **hiérarchie et coordination**
3. Situer les organisations **agiles**
4. Choisir une structure selon la taille et l'activité
5. Diagnostiquer une organisation
