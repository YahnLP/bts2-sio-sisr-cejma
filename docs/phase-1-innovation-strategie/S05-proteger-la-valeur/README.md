> [!NOTE]
> **Question qui guide la séance :** *« Comment empêcher qu'une innovation, un code ou un fichier clients soit repris par d'autres ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Distinguer **brevet, droit d'auteur, secret des affaires**
2. Dire **à qui appartient un logiciel** développé par un salarié ou un prestataire
3. Rédiger l'essentiel d'une **clause de confidentialité** et d'une **clause de non-concurrence**
4. Identifier les **conditions de validité** d'une clause de non-concurrence
5. Argumenter une décision de protection
