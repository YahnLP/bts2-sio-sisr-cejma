> **Question qui guide la séance :** *« Comment analyser la position d'une entreprise pour choisir une direction ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Construire un **diagnostic interne et externe** (SWOT, PESTEL)
2. Appliquer les **cinq forces de Porter**
3. Identifier un **avantage concurrentiel**
4. Calculer une **part de marché** et un taux de croissance
5. Formuler une orientation stratégique argumentée
