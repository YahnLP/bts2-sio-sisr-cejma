# Phase 1 – Innovation, stratégie et création de valeur

**Séances S01 à S05.** Innover, poser un diagnostic stratégique, construire un modèle économique et en calculer la rentabilité, choisir une forme de croissance, protéger sa valeur.

> [!NOTE]
> Chaque séance de 4 h contient une **fiche séance**, un **cours**, une **étude de cas** avec dossier documentaire et un **aide-mémoire**.
