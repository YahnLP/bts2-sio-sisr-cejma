## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Distinguer **croissance interne, externe et conjointe**
2. Comparer rachat, alliance, sous-traitance et recrutement
3. Calculer un **délai de récupération** d'un investissement
4. Situer les modes de **financement** d'un développement
5. Rédiger une recommandation de décision
