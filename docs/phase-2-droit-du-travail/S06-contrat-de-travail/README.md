## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Reconnaître les **éléments** du contrat de travail (prestation, rémunération, subordination)
2. Comparer **CDI, CDD, intérim, alternance, temps partiel**
3. Expliquer la **période d'essai**
4. Citer les **clauses** usuelles et leurs limites
5. Choisir un contrat pour une situation donnée
