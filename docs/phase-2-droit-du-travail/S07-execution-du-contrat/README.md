## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Appliquer la **durée du travail**, les **heures supplémentaires** et le repos
2. Lire un **bulletin de paie** simplifié
3. Situer le **télétravail** et le droit à la déconnexion
4. Calculer une rémunération brute avec heures supplémentaires
5. Résoudre un cas d'exécution du contrat
