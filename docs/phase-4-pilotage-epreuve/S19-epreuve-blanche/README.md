## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Traiter un sujet complet en conditions d'épreuve
2. Mobiliser les **trois champs**
3. Justifier chaque réponse
4. Identifier ses **points faibles**
5. Construire un **plan de révision**
