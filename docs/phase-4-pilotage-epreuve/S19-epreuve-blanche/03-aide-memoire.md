# Aide-mémoire – Épreuve blanche

*BTS SIO SISR 2e année – CEJMA – S19*

> Un mot ou un sigle inconnu ? Passe la souris dessus, ou ouvre le [glossaire](../../ressources/glossaire.md).

## Avant

Méthode de la S18 : questions d'abord, puis dossier ; champ et annexes de chaque question.

## Temps (4 h)

30 min de lecture · 4 dossiers (≈ 50 / 50 / 50 / 45 min) · 15 min de relecture.

## Réponse type

**Notion → application (annexe + chiffre) → conclusion.** Calcul écrit. Conclusion en une phrase.

## Formules à retrouver sans le cours

| Thème | Formules |
|---|---|
| Marché | Part de marché ; part relative |
| Rentabilité | Seuil de rentabilité = charges fixes ÷ marge sur coût variable ; marge de sécurité ; délai de récupération |
| Social | Turnover ; absentéisme |
| Projet | Chemin critique ; marge |
| Pilotage | Marge brute ; EBE ; rentabilité nette ; endettement ; occupation |
| Décision | Note pondérée = Σ (note × poids) |

## Note à la direction

Constat chiffré → analyse (3 champs) → recommandation → conditions → risques.

## Après

Corriger avec la grille ; remplir le tableau des points faibles ; choisir trois séances à revoir.
