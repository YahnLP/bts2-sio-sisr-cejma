> [!NOTE]
> **Question qui guide la séance :** *« Comment traiter un dossier complet en 4 heures ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Lire un **dossier** et repérer les champs
2. Répartir le **temps**
3. Structurer une réponse : **notion, application, conclusion**
4. Écrire une **synthèse** argumentée
5. S'auto-évaluer avec une grille
