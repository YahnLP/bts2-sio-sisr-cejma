## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Croiser les **champs économique, juridique et managériale**
2. Utiliser une **grille de décision pondérée**
3. Évaluer les **risques** d'une option
4. Formuler une **recommandation** structurée
5. Anticiper les **objections**
