## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Construire des **indicateurs pertinents**
2. Lire un **compte de résultat** et un **bilan** simplifiés
3. Calculer **marge, rentabilité, endettement**
4. Concevoir un **tableau de bord**
5. Commenter une dérive
