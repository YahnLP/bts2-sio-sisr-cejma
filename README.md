# CEJMA – BTS SIO 2e année

Cours, études de cas et aide-mémoire de **culture économique, juridique et managériale appliquée (CEJMA)** du BTS SIO option SISR, 2e année : **19 séances de 4 h** pour 19 semaines d'alternance réparties sur l'année, préparant l'épreuve **E4**. ## Principe pédagogique

Une séance de 4 h = une fiche séance, un cours, une étude de cas à partir d'un dossier documentaire fictif, un aide-mémoire. Les entreprises et les chiffres des dossiers sont fictifs. Les corrigés sont hors du site.

## Avancement

| Séances | État |
|---|---|
| S01 à S05 (phase 1) | Rédigées (fiche, cours, étude de cas, aide-mémoire, corrigé) ; **à valider** |
| S06 à S19 | Fiche de séance (objectifs, contenu prévu) ; reste à rédiger phase par phase |
